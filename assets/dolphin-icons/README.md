These four SVGs preserve Will's existing Dolphin toolbar icons. They were copied
from the installed `char-white` icon theme on 2026-09-23. The theme's index credits
Sam Hewitt's FreeDesktop Suru work under GPL3, the original Suru work by Matthieu
James and the Canonical Design Team, and the Suru++ contributors. The theme itself
is packaged as `char-white`. See COPYING for GPL version 3.

Only trailing whitespace was normalized. The generated Dolphin toolbar references installed
user-data copies rather than machine-specific /usr/share/icons paths.
